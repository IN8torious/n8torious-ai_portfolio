# N8toriousAI.com — The Experience

The company site rebuilt as the two-experience doctrine:

- **Act 1 — the World.** `index.html` opens on a full-screen living 3D
  world (`world.html` — the Harakiri Unified galaxy build). No wall of
  text: seven names, a warning label, and one door — ENTER THE TOOLBOX.
- **Act 2 — the Proof.** Below the door: counted receipts (27,811 lines
  in the release snapshot; 19,652 parity checks, 0 failures), the
  ecosystem map, and per-project blocks — what it is, why it exists,
  architecture, source, release.
- `privacy.html` — the privacy page for Temple and future N8torious AI
  applications, unchanged.

The deployed package also carries `img/` screenshots and the Temple
APK; screenshots are binary and ship in the site package rather than
this repository snapshot.
