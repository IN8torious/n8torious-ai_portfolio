# SI Core — The Authored Intelligence Core

The SI Core is the constitutional heart of the N8torious AI system:
one kernel of law — **Actor · Capability · Proposal · Receipt ·
State** — viewed through multiple lenses. *The proposal moves. The
constitution stays.*

**Law D7:** Humans are sources of authority. Systems are never sources
of authority. Systems may only exercise delegated capabilities.

The runnable kernel implementation lives in
[`../si-constitutional-kernel/`](../si-constitutional-kernel/).
This folder holds the SI Core builds themselves.

## Field law (P2.8-A)

Every note inside the core is a field object: its **mass** is counted
from the receipts its lineage authored, its **influence radius** grows
with that mass, and its **force** is formula-counted — Observation and
Creative notes push momentum, Contradiction notes drag in opposition,
Receipt notes anchor and exert no force. Forces govern trajectory
only; law governs outcome. There is no Authority Note: a note cannot
create an approval path.

## Sequence

The line runs in Nathan's order: the compact Core (the Ball) first,
the Onion schematic derived from it, then the one merged file, with
the full music system after the merge.
