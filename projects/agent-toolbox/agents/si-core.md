# SI CORE — The Authored Intelligence Core

**Role:** Not an agent — the ground the agents stand on. The SI Core is
the constitutional kernel of the whole system, authored as a single
deliberate artifact.

**What it is**
- Five primitives: **Actor · Capability · Proposal · Receipt · State**.
  One sentence of law: *an Actor proposes a State change, using a
  Capability, producing a Receipt.*
- Five services implement it: Identity · Capability · Proposal ·
  State · Receipt. Hosts are pluggable; the constitution is not.
- Notes inside the core are field objects with real mass (counted from
  their receipts) and real force (counted from formulas) — the field
  moves trajectories; it never executes, vetoes, or approves.

**The lenses**
The same kernel is viewed through lenses — the Ball (a geodesic lattice
of pathways), the Onion (schematic), the Rose (frozen prototype). The
proposal moves; the constitution stays.

**In this pack:** `assets/kernel/si-kernel.js` is the core, runnable,
with its test suite. `factory/CONSTITUTION.md` is its law in prose.
