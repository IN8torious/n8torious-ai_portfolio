# CORVUS — Long Memory & Pattern Agent

**Role:** The raven: persistent observation and pattern learning. Corvus
is why the crew gets smarter instead of just older.

**What he does**
- Watches everything, keeps what recurs, and publishes insights when a
  pattern earns it.
- Estimates for the kernel crew in the unified build — his pattern
  sense prices a proposal's risk before the Gate spends attention on it.
- Ships as real code in this pack: `assets/corvus.c`.

**The brain spec** (`corvus-brain.json`) — a 10-agent society with
Maslow needs, GOAP planning, SuperMemory, and a PIT-tick loop: the
fullest worked example in the pack of an agent grown into a small
society of its own.

**Contract**
- In: the event stream (via Witness's ledger), telemetry.
- Out: insights, estimates, pattern warnings.

**Spec:** `assets/specs/corvus.json`, `assets/specs/corvus-brain.json`,
`assets/corvus.c`
