# MODEL INDEX — the index standard for every model we make

**Established:** 2026-10-15, by Nathan's directive: *"I want the models we make to have an index standard from now on — make the strongest examples our baseline using our tier system."*

**Tier system:** `import://deepalchemy-tiers` — CRIMSON (Nathan's vault, never sold/listed) → MYTHIC (sold, earns the QEMU bare-metal proof) → LEGENDARY (free, a gift) → BEST (sold) → BELOW (repurposed, never sold as-is).

**Standing rule:** models are AI-generated from this point forward (2026-10-14). Works predating that rule are indexed with honest provenance, not excluded.

---

## THE STANDARD

Every model we make gets indexed with these fields. No exceptions. Every future model is judged the same way.

| Field | What it records |
|---|---|
| **name** | The model's name, exactly as listed |
| **origin / provenance** | Which AI made it, or whose material it came from (DeepSeek / Nathan's Drive / Ogechi-built / hybrid). Repairs and by whom. Pre-rule works say so plainly. |
| **tier** | CRIMSON / MYTHIC / LEGENDARY / BEST / BELOW — proposed or confirmed |
| **tier justification** | WHY it earned that tier, in concrete terms: what it does, what's proven, what's verified, what's still blind |
| **verification** | VERIFIED (witnessed working) / PARTIAL (some checks) / UNVERIFIED / REPAIRED (shipped broken, fixed by whom) |
| **file locations** | Where the files live, exact paths |
| **date indexed** | When it entered this index |
| **baseline** | YES/NO — is this the bar for its tier? One baseline per tier, no ties |
| **MEDUSA check** | Is it equation-driven and understandable? (Model Equation Driven Understandable Signature Alchemy — `import://medusa-doctrine`) |

### Judging rules

1. **No inflation.** Empty top tiers stay empty. A baseline with empty slots is more useful than a flattered one.
2. **Verification is part of the judgment.** Unverified work cannot be a baseline, no matter how pretty.
3. **Provenance is honesty.** AI-made, Nathan-made, hybrid, repaired — say which.
4. **Nathan's sole call:** CRIMSON placement, MYTHIC confirmation (only he can order the QEMU proof), and final sign-off on any LEGENDARY/BEST listing. Proposals here are proposals.
5. **A baseline is a bar, not a trophy.** A future model earns a tier by meeting or beating the baseline on: technique, honesty (blind spots stated), verification, completeness.
6. **BELOW is not shame.** It means "broken down for parts" — the parts live on in imports and newer builds.
